## 🌿 About MediCare

MediCare is a healthcare web application built around a simple idea: accessing healthcare services should feel straightforward.

With a clean interface, organized navigation, and a calming green visual identity, the platform provides an accessible experience for exploring doctors, medical specialties, and appointment-related features.

### Our Vision

> Making healthcare experiences simpler through thoughtful design and technology.

## 🎨 Design Philosophy

MediCare uses a visual style inspired by modern healthcare products.

- **Sage green:** A calm, reassuring brand identity.
- **Clean layouts:** Clear visual hierarchy and readable content.
- **Rounded elements:** A softer, approachable interface.
- **Reusable components:** Consistent interface elements across pages.
- **User-centered navigation:** Straightforward access to key features.

## 🚀 Run Locally

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

**1. Clone the repository**

```bash
git clone https://github.com/aouatef2001/medicare.git
```

**2. Enter the project directory**

```bash
cd medicare
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local address displayed in your terminal.
